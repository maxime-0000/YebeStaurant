# Le Colzotto des Champs

Site vitrine statique, compatible avec GitHub Pages. Les pages sont en HTML et la mise en forme partagée est dans `assets/style.css`. Le menu mobile utilise l’élément HTML `<details>` : aucun PHP ni JavaScript n’est requis.

## Pages

- `index.html` — accueil
- `restaurant.html` — concept du restaurant fictif
- `colzotto.html` — présentation du plat imaginaire
- `recette-colzotto.html` — recette pédagogique
- `beauce-et-inspirations.html` — inspirations réelles, avec sources
- `mentions-legales.html` — mentions légales à compléter après validation

## Publication sur GitHub Pages

Le dépôt est `maxime-0000/YebeStaurant`. Dans GitHub, ouvrir **Settings → Pages**, choisir le déploiement depuis la branche principale et le dossier `/ (root)`. Les liens locaux sont relatifs, donc ils fonctionnent à la racine comme dans le sous-dossier du projet.

Après activation, vérifier la configuration dans `robots.txt` et `sitemap.xml` avec l’URL publique exacte. Compléter également les champs entre crochets des mentions légales avant publication.

Le contenu est un projet pédagogique : aucun restaurant réel, service commercial, commande ou réservation n’existe.
